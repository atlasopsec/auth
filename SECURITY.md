# Security Policy

This module handles authentication, so security reports are taken seriously and handled first.

## Reporting a vulnerability

**Please don't open a public issue for security problems.** Report privately instead, using either:

- **GitHub private vulnerability reporting:** the **Security** tab of this repository → **Report a vulnerability**, or
- **Email:** security@atlasopsec.com

Please include:

- what the issue is and what an attacker could do with it,
- steps to reproduce it, or a proof of concept,
- the version or commit affected.

## What to expect

- An acknowledgement within **3 business days**.
- An assessment and a plan within **10 business days**.
- A fixed release as soon as possible, with credit in the release notes if you'd like it.

Please give us a reasonable time to release a fix before disclosing the issue publicly.

## Supported versions

Before `v1.0.0`, only the latest release receives security fixes. After `v1.0.0`, the latest minor release of each supported major version does.
